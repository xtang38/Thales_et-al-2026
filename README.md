This repository contains the data generated for analysis, results generated from the analysis, and the MATLAB scripts developed for the analysis for manuscript Thales et al. on the parameterization of gene circuit model, with experimental measurement variance.
The AND gate folder contains the noise generation code, the fitting results, the stablized variance, profile likelihood and the MATLAB scripts for the AND gate system. 
The CRISPRi folder contains the noise generation code, the fitting results, the stablized variance, profile likelihood and the MATLAB scripts for the CRISPRi system. 
The shared files folder contains MATLAB scripts used in both systems.
